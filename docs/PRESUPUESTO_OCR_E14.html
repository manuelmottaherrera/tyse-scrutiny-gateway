1. Resumen Ejecutivo

Este documento presenta el análisis de costos para la extracción de texto mediante OCR de los formularios E14 electorales, comparando tres servicios cloud de inteligencia artificial documental.

Contexto del Proyecto

Parámetro Valor
Volumen estimado ~100,000 formularios E14 por escrutinio
Páginas por E14 Variable (2-8 páginas según tipo de elección)
Procesamiento Paralelo (tiempo crítico durante escrutinio)
Flujo E14 (PDF) → MinIO → Servicio OCR → Datos estructurados

Recomendación

AWS Textract es la opción recomendada por su capacidad superior de procesamiento paralelo (100-600 jobs concurrentes), crítico para el tiempo de escrutinio.

4. Procesamiento Paralelo

Importante: El tiempo de procesamiento es crítico durante un escrutinio electoral. La capacidad de procesar documentos en paralelo determina cuánto tiempo tomará extraer los datos de todos los E14.

6. Recomendación Final

Servicio Recomendado: AWS Textract

Justificación:

  1. Capacidad de concurrencia superior: 100-600 jobs paralelos vs 15 TPS de Azure
  2. Tiempo de procesamiento: 6-33 minutos para 100K documentos (crítico para escrutinio)
  3. Sin costo adicional por async: El procesamiento paralelo no tiene sobrecosto
  4. Escalabilidad: Incremento de cuotas sin costo adicional
  5. API madura: SDKs bien documentados para Java/Spring
